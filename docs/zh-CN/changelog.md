# 更新日志

[English](../en/changelog.md) | 简体中文

Codex Agent Bridge 从 0.3.0 开始记录重要变化。

## 未发布

- 标准 `tool_calls` 仅用于需要客户端执行的函数；Codex 自有活动通过 `x_codex.activity` 暴露。

## 0.3.0 — 2026 年 9 月 24 日

- 提供面向本地 `codex app-server` 的 Chat Completions 代理，支持流式输出、客户端函数工具、续写，以及兼容旧的 `codex-openai-proxy` CLI 别名和状态路径。
- 支持用户消息中的内联图片、WAV/MP3 音频与 PDF；通过 `x_codex` 扩展转换内联 CSV、XLSX 和 UTF-8 文本文件，并在模型执行前拒绝不支持的文件 ID。
- 增加 Web 管理台，使用独立管理员鉴权，支持逐客户端密钥、用量记录、模型选择与运行时设置，并按浏览器来源隔离管理员会话。
- 增加持久模型价格表、可选的模型辅助价格查询，以及基于实测 token 用量的美元参考估值；未定价请求仍然可见。
- 支持原生与 Docker 部署、鉴权复用、深色主题，以及仅限原生环境的显式本地管理员免密码登录。
- 增加离线回归测试、只读发布候选验证、源码部署说明和安全报告指引。
