# 本地 Web 管理

[English](../en/admin.md) | 简体中文

可选管理台用于管理命名客户端密钥、请求统计、模型价格与运行时默认值。需要 Node.js 22+，推荐 Node.js 24。

## 启动

```sh
npm ci
npm --prefix web ci
npm run build
npm run build:web
node dist/bin.js serve --agent-service-model gpt-6-luna --admin-port 8789
```

打开 `http://127.0.0.1:8789/admin/`。管理端仅监听回环地址；模型 API 默认使用 8787 端口。管理员登录使用 `<state-dir>/admin/admin-token` 中独立生成的随机口令，首次启动时以仅所有者可读权限创建。请私下读取该文件，或通过 `CODEX_BRIDGE_ADMIN_TOKEN_FILE` 提供自己的文件。不要将管理员口令作为 Agent API key。更换口令文件后需要重启，所有浏览器会话都会失效。

### 记住登录

默认使用密码鉴权。普通会话保存在 `sessionStorage` 中，12 小时后过期；“记住登录”使用 `localStorage`，有效期 30 天并可跨服务重启。两种方式都不会保存管理员密码。更换管理员口令并重启会使所有会话失效，退出登录会立即撤销当前会话。

### 可选的原生本地登录

`--admin-auth local --admin-port 8789` 仅允许可信原生安装免密码进入。会话、CSRF 与严格同源检查仍然生效。容器、转发请求和非回环对端不能使用该模式；代理、隧道或共享桌面场景必须保留密码模式。

模型、请求期限与并发设置对新请求生效，可跨重启保存并覆盖启动值。鉴权来源、监听地址、文件系统根目录和 app-server 策略默认值只能通过 CLI 设置。

## 密钥与浏览器安全

托管客户端密钥可以创建、查看、轮换和停用；列表只显示前缀。查看已有密钥需要管理员密码；轮换需要确认，会立即使旧密钥失效并显示替代密钥。停用只影响新请求。在 agent-service 模式下，未知或停用密钥只会失去用量归属，不会成为访问门槛；local 模式需要另一个有效密钥。

密钥使用 AES-256-GCM 加密，查询使用 SHA-256 摘要。请将 `master.key` 与数据库分别私密备份；主密钥丢失后将无法解密，系统不会降级放行。它只能防护数据库单独泄漏，不能防护宿主账号失陷。

通过环境变量或文件提供的 local 模式密钥不进入密钥表，并记为 `legacy`；应在原始密钥来源处轮换。不要复用管理员口令作为客户端密钥。

管理台通过 `X-Admin-Session` 发送会话 bearer，并按包含端口的浏览器来源隔离。该值仍可被同源脚本读取，因此只能在可信本地浏览器配置中使用。写操作同时校验 CSRF token 和严格同源；模型 API 仍拒绝所有带 `Origin` 的请求。管理响应使用 `no-store`，阻止外部脚本和 framing，并限制登录与查看密钥的尝试频率。该控制台不是公网或多用户系统；密钥分离提供撤销与统计能力，不提供租户隔离。

## 用量统计

仅保存请求 ID、密钥 ID、模型、时间、耗时、状态或错误码，以及上游报告的 token 计数。该模块不保存提示词、回复、工具参数、认证 token 或原始错误文本；诊断日志有独立的敏感数据规则，不会导入控制台。

即使流式客户端不接收 usage 块，用量也来自 app-server 的精确计数。没有匹配请求时显示 0；有请求但没有计数时显示未知。这些值不是订阅额度或账单。

费用是按当前逐模型价格表计算的参考估值。未知模型或计数不完整的请求不计价。历史请求会按当前价格重新估算，因此总额不是历史发票，也不包含长上下文阶梯、工具费、税费或自定义价格等因素。

管理员可以编辑精确模型 ID 的输入、缓存输入和输出价格。可选价格查询只抓取固定的官方价格页面，并在关闭工具与 Web 搜索的情况下发起一次 `gpt-6-luna` 请求。查询输入不包含客户端 API key、管理员凭据或用量数据。该请求记入普通用量；任何建议都必须经管理员复核确认后才能保存。

每个请求 ID 最多写入一次完成记录。SSE 在 HTTP 200 后发生的终止错误仍记为失败；断连与超时分别记为 499/408。进程突然终止可能丢失在途统计，取消后的迟到上游用量可能保持未知。未授权流量和健康检查不生成用量记录。超过 90 天的记录在新记录到达时清理。
