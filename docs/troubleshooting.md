# Troubleshooting

先记录本项目 commit/版本、Node 或 Docker 版本、部署配置类型、客户端版本与错误码。不要直接复制完整日志；使用合成消息复现。健康检查不调用模型，真实对话会消耗上游用量。

| 现象 | 检查与处理 |
| --- | --- |
| 401 / 无法接入 | 使用桥接 API key，不是管理口令或 Codex 凭据；健康与模型列表也要带 Bearer key。 |
| 管理台无法登录 | 源码部署默认 8789，普通 Compose 通过 8787/admin/；读取当前状态目录的 admin-token，容器保持密码模式。 |
| 503 / 未就绪 | 检查本地 Codex 已登录、auth-source 挂载可读、隔离 home 可写；复用认证不会自动发起登录。 |
| 上游认证过期 | 在本地重新登录后重启桥接；并发使用复制的 OAuth refresh token 可能失效。需要独立认证时显式选择 independent。 |
| 自定义提供商不可用 | 认证同步不复制 config.toml；配置隔离 home，并检查模型目录。不要将个人主目录作为容器可写 home。 |
| 429 | 区分本地 overloaded 和上游 usage_limit_exceeded；提高本地并发不能解除上游额度或速率限制。 |
| 503 server_overloaded | 上游模型容量不足，与本机并发配置不同。稍后重试或使用可用模型。 |
| 超时 | 同时检查客户端、网关、桥接与上游超时。延长桥接超时不改变客户端期限。 |
| 历史消息含未知字段 | 确认启用了 agent-service 或 local 兼容配置；无害元数据被忽略，已知字段类型错误仍会被拒绝。 |
| 图片或音频被拒绝 | 当前仅支持文本，不会静默丢弃媒体。 |
| JSON 看起来不逐字流式 | json_schema 输出完成并校验后一次发送；普通文本仍是增量输出。 |
| 工具不能修改宿主机文件 | 客户端工具在客户端执行；Codex 内置工具在桥接环境执行，容器不自动拥有宿主机权限。 |
| Docker 拉取或构建失败 | Docker daemon 代理影响拉镜像，构建代理影响依赖下载；容器里的 localhost 不是宿主机。 |
| 重启后工具续接失败 | 完整提交配对的工具历史或新建会话；持久化不保证恢复在途工作，不要盲目重试有副作用的工具。 |

报错仍存在时，使用 issue 模板提供最小脱敏请求。协议限制见 [客户端 API](client-api.md)、[兼容配置](local-bridge.md)。安全问题按 [SECURITY.md](../SECURITY.md) 私下报告。
